# Learning about Microsoft Technologies

Hey There! This repository contains some of my work that I've put into learning Microsoft Technologies.

## Power BI

Power BI was the first tool that took my attention as I was interested in Data Analysis. It could be said that this tool is something like Excel on steroids. 

I've started my learning journey here by watching the [Power BI Beginner to Pro 2026 Edition - Full Hands-On Tutorial](https://www.youtube.com/watch?v=c-zlMcdIqk0&list=WL&index=3) from Pragmatic Works. That was a really nice kick off as I had no idea how to orientate in this tool.

Another step is to have a look at Maven Analytics for some data and start messing with that.
